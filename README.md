# Φάση 1 — σκελετός, είσοδος, συγχρονισμός

Εφαρμογή για τρεις επιχειρήσεις: καφετέρια, παραγωγή βίντεο, ενοικιαζόμενα δωμάτια.
Χωρίς εργαλεία μεταγλώττισης και χωρίς εξωτερικές βιβλιοθήκες. Ανεβάζεις τα αρχεία και δουλεύει.

## Τι δουλεύει ήδη

- Είσοδος με ρόλους. Ο υπάλληλος βλέπει τρεις οθόνες, ο ιδιοκτήτης όλες.
- Τοπική βάση IndexedDB. Κάθε γραφή περνάει πρώτα από εδώ.
- Συγχρονισμός με ουρά αποστολής, σταδιακή λήψη, και επίλυση συγκρούσεων.
- Λειτουργία χωρίς δίκτυο, με είσοδο για όποιον έχει ήδη συνδεθεί στη συσκευή.
- Ημερήσιο ταμείο καφετέριας, πλήρως λειτουργικό.
- Εγκατάσταση στο κινητό σαν κανονική εφαρμογή.

Οι υπόλοιπες οθόνες ανοίγουν και δηλώνουν σε ποια φάση έρχονται.

## Δοκιμή στον υπολογιστή

Τα ES modules δεν φορτώνουν με διπλό κλικ στο `index.html`. Χρειάζεται διακομιστής:

```bash
cd app
python3 -m http.server 8080
```

Άνοιξε `http://localhost:8080`. Την πρώτη φορά ζητάει να φτιάξεις λογαριασμό ιδιοκτήτη.
Μέχρι να ρυθμιστεί ο Supabase, όλα μένουν στη συσκευή.

## Σύνδεση με τον Supabase

1. Δημιούργησε project στο supabase.com και σημείωσε από τις ρυθμίσεις API
   το **Project URL** και το **anon public key**.
2. SQL Editor → επικόλλησε το `sql/01_phase1.sql` → Run.
3. Authentication → Users → Add user, με το email σου.
4. Στον SQL Editor δώσε στον εαυτό σου τον ρόλο ιδιοκτήτη:
   ```sql
   update public.profiles set role = 'owner' where email = 'το@email.σου';
   ```
5. Συμπλήρωσε τα δύο πεδία στο `js/config.js` και φόρτωσε ξανά.

Οι λογαριασμοί υπαλλήλων φτιάχνονται με τον ίδιο τρόπο και μένουν με τον
προεπιλεγμένο ρόλο `staff`.

## Ανέβασμα στο domain σου

**GitHub Pages:** ανέβασε τον φάκελο σε αποθετήριο, Settings → Pages → Deploy from branch,
και στο Custom domain γράψε το domain σου. Στον πάροχο του domain βάλε εγγραφή CNAME
προς `<χρήστης>.github.io`.

Το HTTPS είναι απαραίτητο, αλλιώς δεν ενεργοποιείται ο service worker και χάνεται
η λειτουργία χωρίς δίκτυο.

## Προσθήκη νέας οθόνης

Τρία σημεία, πάντα τα ίδια:

1. **Πίνακας** στο `js/db.js`, στο `TABLES`. Ανέβασε το `DB_VERSION` κατά ένα.
2. **Οθόνη** στο `js/views.js`:
   ```js
   const suppliers = {
     title: 'Προμηθευτές',
     sub: 'Στοιχεία και τρόπος παραγγελίας',
     async mount(root) { root.innerHTML = '…'; }
   };
   export const VIEWS = { …, 'cafe/suppliers': suppliers };
   ```
3. **Καταχώρηση στο μενού** στο `js/menu.js`, με το ίδιο `key` και τους ρόλους που τη βλέπουν.

Ο πίνακας θέλει και τους αντίστοιχους κανόνες στο SQL, αλλιώς ο server θα αρνείται
τα δεδομένα ακόμα κι όταν η οθόνη τα ζητάει σωστά.

## Δοκιμές

```bash
cd tests
npm install
npm test
```

Ελέγχουν την τοπική βάση, τον συγχρονισμό με προσομοιωμένο server, την επίλυση
συγκρούσεων, την είσοδο και τα δικαιώματα του μενού.

## Δύο πράγματα που δεν υπάρχουν ακόμα

- **Αντίγραφα στο Google Drive.** Έρχονται στη φάση 7, μαζί με το κλειδί κρυπτογράφησης.
  Μέχρι τότε τα δεδομένα ζουν στη συσκευή και στον Supabase.
- **Εικονίδια εφαρμογής.** Το `manifest.webmanifest` έχει άδεια λίστα. Χωρίς αυτά η
  εγκατάσταση στο κινητό δουλεύει, αλλά το εικονίδιο θα είναι το προεπιλεγμένο.
